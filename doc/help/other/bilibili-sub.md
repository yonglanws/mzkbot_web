# 官方B站动态订阅 <Badge type="info" text="新" />

## 📖 功能简介

自动推送**官方账号**和**资讯站**的 B 站动态，让你第一时间获取最新消息。

::: info ✨ 订阅源

- 📢 **官方账号** — 游戏官方动态
- 📰 **资讯站** — 游戏资讯站动态
  :::

## 🎯 使用方法

### 订阅动态

```bash
@mzkbot 订阅
```

### 取消订阅

```bash
@mzkbot 取消订阅
```

## ⚙️ 功能特性

| 特性   | 说明            |
| :--- | :------------ |
| 自动推送 | 新动态发布时自动推送到群聊 |
| 双源订阅 | 同时支持官方和资讯站动态  |
| 随时管理 | 支持随时订阅或取消订阅   |

## ⚠️ 注意事项

::: warning 📌 使用须知

- 订阅后将在群内自动推送动态更新
- 如需停止接收，请使用 `@mzkbot 取消订阅`
- 推送频率取决于账号动态发布频率
  :::
