# 漂流瓶 <Badge type="info" text="新" />

## 📖 功能简介

在群聊中体验**漂流瓶**的乐趣！可以扔出漂流瓶等待他人拾取，也可以捡起别人的漂流瓶查看内容。

::: info ✨ 核心玩法
- 📝 **扔漂流瓶** — 写下你想说的话，扔进大海
- 🧴 **捡漂流瓶** — 随机捡起一个漂流瓶，看看别人说了什么
:::

## 🎯 使用方法

### 扔漂流瓶

```bash
@mzkbot 扔漂流瓶
```

BOT 会提示你输入漂流瓶内容，发送后即可成功扔出。

### 捡漂流瓶

```bash
@mzkbot 捡漂流瓶
```

BOT 会随机返回一个漂流瓶的内容。

## ⚙️ 功能特性

| 特性 | 说明 |
| :--- | :--- |
| AI 审核 | 内置 AI 内容审核，过滤不当内容 |
| 匿名互动 | 漂流瓶内容匿名展示，保护隐私 |
| 随机拾取 | 每次捡漂流瓶都是随机体验 |

## ⚠️ 注意事项

::: warning 🔒 内容规范
- 漂流瓶内容需通过 AI 审核
- 禁止发布违规、敏感或广告内容
- 违规内容将被自动拦截
:::

::: tip 💡 使用建议
- 可以分享心情、许愿、或者留下有趣的话
- 捡到漂流瓶后也可以继续扔出新的
- 请保持友善，共同维护良好的社区氛围
:::
