# 指令帮助 <Badge type="info" text="v2.1" />

欢迎使用 mzkbot ！以下是详细的功能指令指南。

> 💡 小提示：对于手机端用户，你可以随时点击左上角的 `Menu` 按钮调出侧边栏快速切换界面。

::: info 📌 使用前必读

- 大部分指令需要在群聊中 `@mzkbot` 后输入
- HarukiBot 专项功能 不需要 `@mzkbot` 前缀
- 高峰期可能出现延迟，请耐心等待

:::

## 详细使用说明

### 基础对话

| 功能 | 指令 | 说明 |
| :--- | :--- | :--- |
| 基础对话 | `@mzkbot + 内容` | AI 智能对话 |
| 人格切换 | `@mzkbot 人格切换` | 切换对话人格 |

### 视频对话 & 剧本生成

| 功能 | 指令 | 说明 |
| :--- | :--- | :--- |
| 视频对话 | `@mzkbot 视频对话 + 内容` | 生成视频回复 |
| 剧本生成 | `@mzkbot 剧本生成 + 内容` | 生成2-3分钟视频 |

::: danger ⚠️ 注意
- 已接入**违禁词检测系统**，请不要使用此功能进行违规操作
- 请勿利用此功能进行盈利制作
- 两个功能目前还不太稳定，如有问题请联系开发者
:::
