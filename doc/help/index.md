# 指令帮助

欢迎使用 mzkbot ！以下是详细的功能指令指南。

> 💡 小提示：对于手机端用户，你可以随时点击左上角的 `Menu` 按钮调出侧边栏快速切换界面。

::: info 📌 使用前必读

- 大部分指令需要在群聊中 `@mzkbot` 后输入，部分指令无需@，直接发送即可
- 高峰期Bot可能会出现延迟，请耐心等待
- 对于官方机，建议保持开启 `获取群内全部消息` 和 `主动消息` ，以获取更好的体验
- 官方机目前无法拉群，请耐心等待腾讯未来是否开放
:::

## 详细使用说明

### 基础对话 {#基础对话}

| 功能 | 指令 | 说明 |
| :--- | :--- | :--- |
| 基础对话 | `@mzkbot + 除常规指令外的所有内容` | AI 智能对话 |
| 人格切换 | `@mzkbot 人格切换` | 切换对话人格 |
| 人格切换 | `@mzkbot 人格切换 人格名` | 快速切换对话人格 |

### 视频对话 & 剧本生成 {#视频对话--剧本生成}

| 功能 | 指令 | 说明 |
| :--- | :--- | :--- |
| 视频对话 | `@mzkbot 视频对话 + 内容` | 生成视频回复 |
| 剧本生成 | `@mzkbot 剧本生成 + 内容` | 生成2-3分钟视频 |

::: danger ⚠️ 注意
- 请不要使用此功能进行违规操作
- 请勿利用此功能进行盈利制作
- 视频由 MySekaiStoryteller 项目生成，制作与公开传播须遵守[视频制作、分发许可协议](/help/guize#视频许可)（仅限非商业用途、传播需署名）
:::

### 每日签到 {#每日签到}

| 方式 | 指令 |
| :--- | :--- |
| @机器人 | `@mzkbot 签到` |
| 直接发送 | `签到` |

你也可以发送 `@mzkbot 签到 角色` 来获取对应角色的签到图片

### AI语音生成

| 用法 | 示例 | 说明 |
| --- | --- | --- |
| `说 <内容>` | `说 你好` | 用当前人格的音色合成语音 |
| `说 <内容> <人格>` | `说 你好 瑞希` | 指定人格音色，人格名可放后面，也可放前面 |
| `说 <内容> <人格> <语言>` | `说 你好 瑞希 日` | 指定人格 + 指定语言，人格与语言顺序不限 |

部分人格暂无语音模型，如果你想贡献你微调的GPT-SoVITS模型文件，欢迎联系作者

当前有语音模型的角色有:VBS全员，25时全员，Mujica全员，MyGO全员，神代类


### 图库 {#图库}

| 功能 | 指令 |
| --- | --- |
| 随机/指定数量/倒数第 N 张（中文指令后可以不空格） | `看 画廊名` / `看画廊名` / `看 画廊名 x2` / `看 画廊名 -1` |
| 按 pid 看图 | `看 123 456` / `看 -1` |
| 查看所有画廊列表 | `看所有` / `看全部` |
| 查看指定画廊图片网格 | `看所有 画廊名` |
| 上传（回复图片），加 `force` 禁用查重 | `上传 画廊名` / `添加 画廊名` |
| 撤销自己最近一次上传 | `取消上传` / `撤销上传` |
| 查看上传记录 | `上传记录 记录ID` |

请不要上传与画廊名无关的图片。
