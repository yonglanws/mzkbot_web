# 舞萌DX服务器状态 <Badge type="info" text="新" />

## 📖 功能简介

查询 **舞萌DX (maimai でらっくす)** 游戏服务器的当前状态，快速了解服务器是否正常运行。

::: info ✨ 适用场景
- 🎮 想确认服务器是否维护
- 🔍 游戏连接异常时排查原因
- 📊 查看服务器实时状态
:::

## 🎯 使用方法

```bash
@mzkbot 舞萌状态
```

## ⚙️ 功能特性

| 特性 | 说明 |
| :--- | :--- |
| 实时查询 | 获取服务器最新状态 |
| 快速响应 | 即时返回查询结果 |
| 状态展示 | 清晰展示运行状态信息 |

## ⚠️ 注意事项

::: warning 📌 使用须知
- 查询结果仅供参考，以官方公告为准
- 服务器维护期间可能无法查询到准确信息
- 如遇网络波动，响应时间可能较长
:::
