# 使用 BOT 的规范 <Badge type="danger" text="必读" />

::: tip ⚠️ 重要提醒
请仔细阅读并遵守以下规则，共同维护良好的 BOT 使用环境。违反规则可能导致功能限制或封禁。
:::

## 🚫 红线规则（禁止行为）

| 序号 | 行为                | 说明                              |
| :- | :---------------- | :------------------------------ |
| 1  | 🚫 **不准辱骂 BOT**   | 对 BOT 使用不尊重的言语，包括但不限于辱骂、人身攻击等行为 |
| 2  | 🚫 **不准刷屏**       | 在群聊中频繁调用 BOT 发送大量消息，造成群聊混乱或干扰他人 |
| 3  | 🚫 **不准间接表达不适言论** | 通过 BOT 间接发布包含敏感、歧视、引战或令人不适的内容   |
| 4  | 🚫 **不准拉入无关群聊**   | 将 BOT 添加至与 PJSK 无关的群聊（例如无关社交群等） |

## ⚠️ 黄线规则（需注意行为）

| 序号 | 行为             | 风险说明                             |
| :- | :------------- | :------------------------------- |
| 1  | ⚠️ **避免高频操作**  | 短时间内发送大量请求可能导致 BOT 触发风控，影响正常使用体验 |
| 2  | ⚠️ **拉群需同意申请** | 非管理员拉群请事先与群管理员协商好，默认拉群时已经过所有管理同意 |

## 📋 违规处理说明

当使用者恶意破坏/恶意滥用bot，我们可能会披露使用者的个人信息

## 🎬 视频制作、分发许可 {#视频许可}

mzkbot 的**视频对话**与**剧本生成**功能基于开源项目 **MySekaiStoryteller** 实现。使用这些功能录制、生成视频，即视为使用 MySekaiStoryteller 项目录制视频，须遵守项目方发布的以下许可协议：

### MySekaiStoryteller 视频制作、分发许可协议

本协议由 **MySekaiStoryteller 项目方**（即 _Untitled-Story Organization_，以下简称"项目方"）
与使用本项目录制视频的用户（以下简称"用户"）共同订立。

用户通过本项目录制、生成、导出视频的行为，视为已完整阅读并同意本协议全部条款。

### 一、定义

#### 1. 项目录制视频

指用户通过 **MySekaiStoryteller** 项目的功能（包括但不限于录制、生成、导出等）
直接产出的视频文件，以及对该文件进行**不改变内容主体的简单编辑**后形成的衍生版本，包括但不限于：

- 裁剪视频时长
- 添加字幕、简单画面拼接

不包括对视频核心内容、表现主体或性质产生实质性改变的深度改编作品。

#### 3. 责任的免除

项目方仅提供 **MySekaiStoryteller 的技术工具与软件功能**，

### 三、项目录制视频的使用限制

#### 1. 使用原则

原则上，项目录制视频**仅限非商业用途**，不得用于规模化、平台化或以视频本身作为盈利核心的商业行为，包括但不限于：

- 广告、带货、品牌宣传等商业推广用途；
- 付费解锁、会员专享、付费课程素材等直接收费传播形式；
- 将项目录制视频作为可重复出售、授权或分发的商品；
- 作为商业网站、商业 App 的流量或盈利内容；
- 明确以盈利为目的长期运营的视频账号、素材账号。

同时**不允许用户使用本项目为他人提供有偿的视频制作服务**，例如：

- 同人创作委托
- 剧情定制视频
- 个人纪念视频
- 非商业用途的个性化定制作品

#### 2. 署名要求

任何公开传播项目录制视频的行为，需在显著位置标注使用了本项目，方式包括但不限于：

- 在视频简介或详情页中标注
  > "本视频由 MySekaiStoryteller 录制"
- 在视频内容中以字幕、语音等形式说明使用了本项目；
- 在视频标签或相关说明中添加 **MySekaiStoryteller** 标识。

#### 3. 传播范围说明

项目录制视频可在合法、非商业的场景下进行传播与分享。

若项目录制视频涉及有偿委托或定制制作，其后续传播方式、使用范围及合规责任，
由用户或委托人自行承担，与项目方无关。

若用户违反本协议约定，项目方有权采取包括但不限于以下措施：
